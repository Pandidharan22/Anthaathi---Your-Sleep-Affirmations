# Ambience beds

Bundled, seamless-looping background beds for the audio studio (FR-304). Produced from the
CC0 originals in `source/` (git-ignored) by `scripts/make-beds.py`: crossfaded into a loop,
loudness-matched to the same level, encoded as 96 kbps stereo MP3.

| File | Title / author | Source | License |
|---|---|---|---|
| `rain.mp3` | Rain.wav — idomusics (first 45s only; a vehicle is faintly audible after ~46s) | https://freesound.org/people/idomusics/sounds/518863/ | CC0 |
| `ocean.mp3` | Sea Waves with Tern Calls — Joseph Sardin | https://bigsoundbank.com/sea-waves-and-seagulls-s0267.html | CC0 |
| `crickets.mp3` | Ambience Night Field Cricket 01 — sengjinn | https://freesound.org/people/sengjinn/sounds/175020/ | CC0 |
| `pad.mp3` | Ambient F Sharp Minor Ethereal Choir Pad 1 — deadrobotmusic | https://freesound.org/people/deadrobotmusic/sounds/808032/ | CC0 |

CC0 requires no attribution; credits are kept here for provenance. Licence status was read
from each source page on 2026-10-06. `pad.mp3` is a 10s–130s excerpt of a 3:38 original.
