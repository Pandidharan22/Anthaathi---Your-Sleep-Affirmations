# Architecture Decision Records — Anthaathi

Each ADR captures one significant technical decision: the context that forced it, the options considered, and why one was chosen. New ADRs are numbered sequentially and never renumbered — a reversed decision gets a new ADR marked `Superseded by ADR-xxxx`, with the old one's status updated to `Superseded`, so the history stays intact.
